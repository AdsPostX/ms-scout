<objective>
## Goal
Publisher drill modal — when a user clicks "Drill Publisher" on a publisher-related
MONITOR_ALARM card, open a modal with a revenue + conversion summary for that publisher
covering the last 7 days.

## Architecture decision (decided here — see STATE.md)
**Loading modal pattern.** Chosen over async pre-fetch because:
- trigger_id expires in 3 seconds — a ClickHouse query cannot block the modal open
- views.update is the standard Slack pattern for slow data loads
- Async pre-fetch requires background caching which adds infrastructure

**Flow:**
1. User clicks "Drill Publisher" button (action_id="scout_drill_publisher", value=pub_id)
2. Handler immediately calls `views_open(trigger_id, loading_modal)` — < 50ms
3. Handler spawns a daemon thread to run `get_publisher_drill_summary(pub_id)`
4. Thread calls `views_update(view_id, data_modal)` when query completes
5. If query fails, `views_update` shows an error state modal

## p95 gate
This pattern is safe regardless of ClickHouse p95 latency because the loading modal
absorbs any wait. The gate in STATE.md was written before the loading modal pattern was
decided. It is resolved here — proceed unconditionally.

## Output
- `queries_revenue.py` — `get_publisher_drill_summary(pub_id)` function
- `scout_ui_kit.py` — `_drill_loading_modal()` + `_drill_data_modal(summary)` builders
- `scout_handlers.py` — `_handle_drill_publisher` handler + `_BLOCK_ACTION_DISPATCH` entry

    ```python
    def _handle_drill_publisher(action: dict, payload: dict, web: WebClient) -> None:
        """Open loading modal, then async-fetch pub drill summary and update modal."""
        import threading as _threading
        ctx = _extract_interaction_context(payload)
        channel = ctx["channel"]
        user_id = ctx["user_id"]
        trigger_id = payload.get("trigger_id", "")
        pub_id = action.get("value", "")

        if not trigger_id:
            log.warning("[drill_publisher] no trigger_id in payload")
            return

        from scout_ui_kit import _drill_loading_modal, _drill_data_modal, _drill_error_modal

        # Open loading modal immediately — must happen within 3s of button click
        try:
            open_resp = web.views_open(trigger_id=trigger_id, view=_drill_loading_modal())
            view_id = open_resp["view"]["id"]
        except Exception as e:
            log.warning("[drill_publisher] views_open failed: %s", e)
            return

        def _fetch_and_update():
            try:
                from queries_revenue import get_publisher_drill_summary
                summary = get_publisher_drill_summary(pub_id)
                updated_view = _drill_data_modal(summary)
            except Exception as e:
                log.warning("[drill_publisher] query failed for %s: %s", pub_id, e)
                updated_view = _drill_error_modal()
            try:
                web.views_update(view_id=view_id, view=updated_view)
            except Exception as e:
                log.warning("[drill_publisher] views_update failed: %s", e)

        t = _threading.Thread(target=_fetch_and_update, daemon=True)
        t.start()
    ```
